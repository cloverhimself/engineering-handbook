# Portfolio / Static Site Profile

Use for portfolios, brochure sites, landing pages, small marketing sites, and mostly static content.

Priorities:
- keep architecture minimal;
- prefer static generation or simple server rendering when appropriate;
- optimize images and media delivery;
- keep dependencies small;
- prioritize accessibility, responsive layout, metadata, SEO, and fast loading;
- avoid adding databases, authentication, APIs, queues, or backend services unless a real feature requires them;
- keep content structure easy to update;
- use semantic HTML and standard browser behavior;
- treat contact forms and external integrations as isolated boundaries;
- measure performance before adding caching layers beyond normal platform/CDN capabilities.

The default for this profile is simplicity, not application architecture.
